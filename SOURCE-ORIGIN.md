# Source origin and update policy

This is a fresh, allowlisted source export based on SM64coopdx v1.5.1
(8cd6e5977d9f920d51ca71f2c61801d019ed79c6), with the Super Rocket 64 changes.
No prior private repository history, personal inputs, extracted game profiles,
saves or credentials are required or included. See credits.txt and licenses/.

Maintain gameplay upstream in the development project. For a public update,
review its source diff, carry only relevant code and declared resource inputs
into this repository, run the build/setup checks, and publish a new source
commit and matching release. Do not merge or push private repository history.
Public users and builders need only this repository and public dependencies.
